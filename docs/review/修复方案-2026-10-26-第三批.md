## 1. 阶段 A — 离线可验证的小修

### P6 列表项内的非列表块清空列表层级

**现状**:`parser.ts` 主循环轮首,「上一个产出块不是列表项」就清空缩进栈(`listIndents.length = 0`、`listContentCol = null`)。列表项**内部**的代码块(A4 缩进围栏)或独占行图片也会触发清空,于是 `- a\n  ```js\n  x\n  ```\n  - b` 里的 `b` 层级为 0(应为 1)。

**修法**:记下「上一个块是否属于当前列表项内部」——产出非列表块时,若它的起行缩进 ≥ `listContentCol`(列表内的缩进围栏、缩进图片行等),标记 `prevInList = true`;轮首的清栈条件改为「上一个块不是列表项 **且** 不在列表项内部」。只影响缩进到列表内容列以内的块,顶格的块照旧结束列表。X 目前把嵌套列表压平,此项主要保证 depth 数据正确。

**测试**:审查两例(代码块 / 图片之后 `b` 的 depth 为 1);顶格代码块之后的列表从 0 起算(行为不变);与 backlog P4(4 空格缩进 / Tab)的用例互不影响;新旧差分(只允许含列表内缩进块的输入有差异)。

### P11 能力面板计数口径(四处)

1. **行内代码里的标记被误计**:`` `[^1]` ``、`` `![a](b.png)` `` 被计为脚注 / 行内图片。修:计数前先把文本里的行内代码段(`` `…` ``,X 不支持行内代码、反引号原样保留)剔除。
2. **行内 HTML 注释无提示**:段落中间的 `<!-- x -->`(第二批 P3 只处理块级注释)原样写入 X 却没有告知。修:新增 warn「行内 HTML 注释 · 原样写入」,按出现次数计。
3. **`#### 四级` 双重计数**:同时计为「原生加粗」与「降级标题」。修:降级标题块(`isDemotedHeading`)的整段 BOLD 不计入「粗体 / 斜体 / 删除线」。
4. **导入报告统计的是原始 md**:`h1Handle=remove` 去掉的标题、`coverKeep=remove` 去掉的首图仍被计入。修:`capability` 增加可选参数 `adjust: { removeTitle?: boolean; removeCoverImage?: boolean }`,与写入流程同一判定;`buildRunRecord` / 报告快照带上它,报告卡按它重算明细。历史记录项不需要新字段(历史页不重算能力面板)。

**测试**:四处各一例;既有能力面板用例不变。

### P12 空 ATX 标题 ⚠️ 待定

**现状**:`#` → 段落 `#`;`# #` → 一级标题 `#`;`#### ####` → 加粗段落 `####`。CommonMark 下三者都是**空标题**。

- **A(推荐)· 不产出块**:空标题没有内容,写进 X 是一个空的标题块(光标落上去会是标题样式),对读者无意义;标题抽取本就跳过空标题。
- B · 产出空的 header-one(严格对齐 CommonMark 渲染)。

**测试**:三例;`#标题`(无空格,不是标题)维持段落;`# 标题 #` 照常。

### H1 历史列表的保存回声竞态

**现状**:`WorkspaceProvider` 历史同步按「长度 + id 序列」判回声。连续两次 `commitHistory` 时,前一次较慢写入的回声若晚于后一次才到,会被当成外部变更采纳,列表短暂回退;后一次的回声到达时自愈,不丢数据。

**修法**:复用第一批的 `createEchoQueue`,登记每次写入的 id 序列签名(`ids.join('\u0001')`),回声命中即吞掉;判定抽成纯函数(与 `decideDraftChange` 同形),单测覆盖竞态时序。

### O5 / O7 / O8 小优化

### 真机取证脚本(在 X 文章编辑页的 DevTools Console 执行,只读不改)

> **正式版见 [`docs/qa/真机取证脚本-第三批阶段B.md`](../qa/真机取证脚本-第三批阶段B.md)**(与 injector 同口径的定位与打分、场景表、判定规则;下面是方案阶段的草稿,保留作对照)。

```js
// E1 · 标题框(I5):列出所有候选输入框的 tag / aria-label / placeholder / data-testid
[...document.querySelectorAll('input, textarea, [contenteditable]')].map(el => ({
  tag: el.tagName, aria: el.getAttribute('aria-label'), ph: el.getAttribute('placeholder'),
  testid: el.getAttribute('data-testid'), w: Math.round(el.getBoundingClientRect().width),
}));
// E2 · 封面输入(I6):在「已有封面」和「无封面」两种文章里各跑一次
[...document.querySelectorAll('input[type="file"]')].map(i => ({ accept: i.getAttribute('accept'), testid: i.getAttribute('data-testid') }));
// E3 · 正文最后一块(I7):写入一篇以代码块结尾的文章后跑,再手动试着在代码块之后点击输入
[...document.querySelectorAll('[data-testid="composer"] [data-block="true"]')].slice(-3).map(b => b.outerHTML.slice(0, 160));
```

另请在**英文以外**的 X 界面语言(如日语 / 西班牙语)下跑一次 E1。

### I2 空稿取样 `x` 残留

**现状**:空草稿为取样执行 `execCommand('insertText', 'x')`;之后若在主提交前判定切文章、或取样轮询失败,`x` 留在编辑器里。
**修法**:①把「切文章」复查挪到插入 `x` **之前**(插入后到提交前只剩同步构造,不再有等待窗口);②取样失败时,若编辑器正文恰为 `x`,用 `execCommand('undo')` 撤回这次插入(撤回失败不再重试,如实报错)。
**验证**:真机——新建空文章,导入时在取样期间切走(需配合 DevTools 断点),确认无 `x` 残留。

### I4 滚动到顶部选错元素

**现状**:`content.ts` `scrollEditorToTop` 取页面第一个 `[contenteditable="true"]`,可能是标题以外的其他可编辑区。
**修法**:与 injector 的编辑器定位同口径——优先 `[contenteditable='true'][data-testid='composer']`,再 `.public-DraftEditor-content`,最后才是裸 contenteditable。逻辑抽成共享的选择器层级常量,injector 与 content 共用。
**验证**:真机——长文写入后开「完成后滚动到顶部」,确认回到正文开头。

### I5 / I6 / I7(取证后再定)

- **I5 标题框**:若 E1 显示标题框的 `data-testid` 稳定且不随语言变化,打分规则加一条「`data-testid` 精确匹配」作为最高优先;若没有稳定属性,改为「文章编辑区内、位于正文编辑器上方的第一个 textarea」的结构定位,关键词作为补充而非硬门槛(仍须排除正文编辑器本身,防 HANDOFF §8 记过的「清空正文」事故)。
- **I6 已有封面**:若 E2 显示已有封面时没有可用的 file input,`setCoverImage` 在找不到输入框时先判断「页面上已有封面图」→ 返回新状态 `cover-exists`(报告文案「文章已有封面,未替换」,不计失败);是否点「更换封面」入口自动替换,取证后再评估(涉及点击页面按钮,有误点风险)。
- **I7 atomic 前后光标**:若 E3 证实以 atomic 结尾无法继续输入,写入时在文末 atomic 块之后补一个空段落(与 X 原生插入 atomic 的行为一致);开头 atomic、相邻 atomic 视取证结果决定是否也补。
