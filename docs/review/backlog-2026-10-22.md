### 本地图与链接(旧问题,优先级低,2026-10-23 复审推迟)
- **本地图路径边角**:绝对路径(`/Users/…`、盘符)一律按非法拒绝、不尝试在文件夹内按尾部匹配;文件名含 `#` / `?` 时被当成 query / hash 剥掉(已有「剥后读不到再按原串试一次」兜底,但索引层未覆盖);**大小写**不敏感文件系统与 **Unicode NFC / NFD**(macOS 文件名 NFD、md 里 NFC)导致同一张图匹配不上。
- **本地文件无 magic-byte 嗅探**:本地图只按扩展名 / MIME 判类型(dataURI 同样,见 B12),改名的非图片文件会被当图上传。
- **协议相对地址 `//host/x.png`**:`classifyImageSource` 归为远程,但权限申请的 `originPatternOf` 只认 `http(s)://` 开头,该 origin 不会进申请弹窗;后续 background 抓取对无协议地址的行为未专门验证(很可能 fetch 失败降级)。需补规范化(按 https 补全)并覆盖权限申请 / 计数 / 抓取三处。
