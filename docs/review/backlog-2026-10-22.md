## 2. 本轮 code review 留下的 advisory

- **C2 两窗口交错写入短暂分叉**:设置/主题多窗口同步按「键排序 JSON」判回声,两窗口几乎同时写不同字段时可能短暂各自为政,下一次写入后收敛。
- **C25 提示张数偏大**:权限被拒 toast 的「N 张远程图」按块计,同一张图多处引用 / 封面复用时会多数。
- **A3 松散列表只剥首段**:列表续行吸收对「松散列表(项间空行)」只处理首段,后续段落仍成独立块。
- **A7 `inlinePlainText` 固定 `wikilink=true`**:标题抽取不跟随用户 wikilink 开关,关闭时 `[[x]]` 在标题里仍被转成纯文本。
- **orphan 审计重复记账**:末轮 FIFO 追回后孤儿审计与超时失败明细可能对同一张图各记一条。
- **跨行内代码的病态段落约 1.4s**:`noCloseFrom` 缓存在跨过行内代码时停写,大量反引号 + 未闭合强调符的段落仍可达 ~1.4s。
- **ErrorBoundary 硬编码 storage key**:兜底 UI 里自带的 key 字符串未引用各 store 导出的常量,将来改 key 会漂移。
- **IPv6 组播未拦**:B10 补了 IPv4 ≥224 组播段,IPv6 `ff00::/8` 组播仍放行(实际可达性低)。
