- **标题**：X 标题框 = "MarkFlow 全格式测试样例"（来自 frontmatter，优先于 H1）
- **封面**：文章封面已设好，Edit media 裁剪弹窗已自动关闭

- **任务列表**：☐ / ☑ 符号正确；「带粗体的任务」里加粗只落在「粗体」两字上，没被符号带偏
- **全角空格列表项**：正常成为列表项，没留下 `-　` 字面量
- **图片**：独占行的图片已真实上传；行内图片保留为 markdown 原文
- **代码块 / 表格 / 分割线 / 推文**：均为 X 原生块，非图片
- **能力面板**：列出「行内图片 / 脚注 / HTML 块 / 数学公式」warn 项，以及「多级列表」（special）「任务列表」（warn）
